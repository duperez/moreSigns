# Changelog

## 2.0.0 (NeoForge 1.21.1)

Port from Forge 1.20.1 to NeoForge 1.21.1 (21.1.259), Java 21, ModDevGradle.

### Content
- Custom signs: a frame (border and post) plus a board (the plate you write on). Each part is a block id plus an optional dye tint, stored in the data components `moresigns:part` (frame and board items) and `moresigns:sign_parts` (sign item and block entity). The texture of a part is the texture of its block. Blocks `custom_sign` and `custom_wall_sign`; items `sign_frame`, `sign_board`, `custom_sign`. Drops keep the parts and pick block returns the right sign.
- Text color defaults once to white or black by WCAG contrast against the board's map color, tinted by the dye. Glass-like blocks without a map color count as light.
- Sign Workbench (`sign_workbench`), crafted shapeless from a crafting table and any sign (tag `minecraft:signs`). Four modes in tabs on the left of the panel: Make parts (1 block gives 1 frame or 2 boards, the block is consumed), Paint (a dye tints a frame or board and is not consumed; a wash button removes paint), Assemble (frame + board gives a sign), Take apart (sign gives frame + board with their colors; taking either result gives the other too; shift-click does a whole stack). Live rotating 3D preview, ghost icons and tooltips on empty slots, one hint line, shift-click support. UI reasoning is in `docs/workbench-ui-design.md`.
- Accepted materials are the block tag `moresigns:sign_materials`: planks, wool, terracotta, stone bricks, bricks, nether bricks, quartz block, smooth stone, bone block, prismarine, cut copper, and the `c:` tags storage_blocks, glass_blocks, concretes, stones, cobblestones, obsidians. Blocks from other mods in those tags are accepted; a data pack can add more by editing the tag.
- The creative tab lists the workbench, canvas, the 19 canvas signs, and sample frames, boards and signs for every planks plus iron, gold, copper, diamond, emerald, netherite, glass, stone, stone bricks, bricks, quartz and obsidian.
- Languages: English (default), Portuguese (pt_br, pt_pt) and Spanish (es_es, es_mx, es_ar, es_cl, es_uy, es_ve), generated by datagen from `data/Translations.java`.
- Art: the workbench block model and textures, all GUI sprites and tab icons are generated by `tools/generate_art.py` (pure Python, deterministic).
- Canvas signs: plain, 16 dye colors and 2 hand-painted (`orange_purple`, `green_gradient`), each with standing and wall variants.
- Canvas item, usable as fuel (400 ticks).
- Recipes: canvas from string, canvas sign, dye recoloring from any canvas sign, and book, painting and scaffolding from canvas.
- Registry names of existing signs and the block entity id `moresigns:canvas_sign` are unchanged from 1.20.1.

### Changed
- All variants are defined in one list, `CanvasVariants`, which drives blocks, items, WoodTypes, blockstates, item models, recipes, loot, tags and lang. Data is generated with `./gradlew runData` and committed in `src/generated`.
- Each canvas variant has its own vanilla `WoodType` (`moresigns:canvas_<key>`); the vanilla sign renderer and edit screen draw them. The 1.20.1 custom renderer, edit screen and mixins were removed.
- Custom signs use a new custom renderer (`CustomSignModel`, `CustomSignRenderer`, `CustomSignItemRenderer`). Their edit screen is swapped via `ScreenEvent.Opening` and an access transformer (`META-INF/accesstransformer.cfg`) and draws the real sign. Hidden coplanar faces are not drawn.
- Added JUnit tests (`./gradlew test`: variant naming, `LanguageFilesTest`) and 19 game tests (`./gradlew runGameTestServer`, including the workbench menu flows). The game tests are in the test source set, so they are not in the jar.

### Fixed
- The canvas sign edit lock is now released (ticker override).
- A workbench menu bug found by the game tests (result slot index).
- Pick block on a custom sign.
- Text color was not repainted when placing a sign.
- GUI lighting was left flat after drawing the workbench preview.
- Z-fighting on glass-like parts (hidden coplanar faces are no longer drawn).
- Removed the odd recipe that turned a canvas sign plus white dye into plain Canvas.

### Removed
- Canvas Rug. The block existed without an item or textures, and its recipes referenced a non-existent item. It can be restored from branch `1.20.x`.
- Forge-only dependencies (CraftTweaker, AppleSkin, JEI stubs).
- Unused template code: loot modifiers, custom recipe types, placement modifiers, util classes.

### Known issues
- The 19 canvas signs are separate from the custom signs and cannot be taken apart.
- Paint is a tint of the block texture (16 vanilla dyes only), so it can look muddy on blocks that already have color.
- Every material costs 1 block, whatever its rarity (a block of iron costs the same as a plank).
- Taking a sign apart with a nearly full inventory can drop one of the two parts on the ground. Nothing is lost.
- No JEI/REI integration for the workbench.
- Gradient canvas signs have no dye recipe (creative only).
